# DD0009: Declare every public interface, abstract class and delegate

|  |  |
| --- | --- |
| **Id** | `DD0009` |
| **Tier** | 1 (error, mechanical, single compilation) |
| **Severity** | error |
| **Motivating decision** | `Contracts.ContractsCarryAttribute` |
| **Introduced in** | 0.1.0-preview.1 |

## Principle

A public interface is a promise to everyone who can see it, and the promise outlives whoever made
it. There is no size at which that stops being true.

## What the rule checks

In a project with `ArchLayer` declared, every externally visible interface, abstract class and
delegate carries `[Contract(typeof(<Set>.<Key>), Role = "…")]`.

Externally visible means public all the way out: a public interface nested inside an internal class
is not reported, because nobody outside the assembly can name it and so nothing outside can depend
on it.

No member count is involved. Every threshold that was tried measured the wrong thing — a
three-member interface can be one segregation failure and a four-member streaming sink none — so
what is asked for is the thing actually wanted: that somebody decided to expose it.

A partial type is reported on each of its parts, because one part is where somebody will add the
attribute and a diagnostic on only the other sends them to a file that looks fine.

## Configuration

| Setting | Where | Default | Effect |
| --- | --- | --- | --- |
| `ArchLayer` | MSBuild property | none | The rule runs only when this is set. A project that never declared a layer has not adopted the contract rules. |
| `ArchCompositionRoot` | MSBuild property | `false` | `true` excludes the project. |
| `dotnet_diagnostic.DD0009.severity` | `.editorconfig` | `error` (tier 1) | Downgrading it below `error` is DD0008. |

With nothing configured the rule does not run at all — not "runs and finds nothing". A consumer who
has not set `ArchLayer` is getting no contract checking, and should know that rather than conclude
their surface is clean.

`*.Tests` assemblies are excluded and this is not configurable: a test assembly's public surface is
a list of tests, not a package surface.

## False-positive story

Tier 1 and decidable: accessibility and type kind, both in the compilation.

The edge is a public abstract class used as an implementation base rather than as a surface —
a template-method base nobody outside is expected to derive from. The rule reports it, and the
answer is usually that it should not be public. If it should, that is a decision, and
`[DesignDecision]` on the type is where it is recorded.

## Applying the fixes

`dotnet build` never runs a code fix, so a fix that only an IDE can reach is invisible to anyone
working from a terminal — an agent included. From a terminal:

```
dotnet format analyzers --diagnostics DD0009
```

No fix is registered. The attribute needs a decision key, and there is no key to insert until a
decision is filed; a code action that inserted a plausible-looking one would be writing a ledger
entry from inside an editor, which is the thing this whole design exists to prevent. The other
answer — making the type internal — is a visibility change with consequences a fix cannot see.

## Violating example

```csharp
// in a project with ArchLayer=1
namespace Consumer
{
    public interface IQuadSource
    {
        int Read();
    }
}
```

```text
DD0009: public interface 'Consumer.IQuadSource' is part of this assembly's surface and cites no decision.
Decide: make it internal if nothing outside needs it, or mark it [Contract(typeof(<Set>.<Key>), Role = "...")] citing the decision that says this is a contract | mark it [DesignDecision(typeof(<Set>.<Key>), Scope = ExceptionScope.<Scope>)] citing the accepted decision that says so.
Do not add the attribute without a decision that answers this; if the reason is only that the code already looked like this, take the design change.
```

## Conforming example

```csharp
namespace Consumer
{
    [Contract(typeof(CatalogShape.ProductLookupContract), Role = "catalog read side")]
    public interface IProductLookup
    {
        Product? Find(ProductId id);
    }
}
```
