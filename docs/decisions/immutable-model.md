decisions:
  - key: DomainModelImmutable
    statement: "DD0019: public DomainModel types (effectively public: the type and every type containing it) have init-only setters, readonly fields, readonly structs and no mutable collection members. Method bodies too: a non-private instance method on a model class that writes an instance field or property of its own, or invokes a member of a field whose type is mutable by DD0004's test, is reported, directly or through one private helper in the same type. A call that only reads the field is not a mutation: a member of IReadOnlyCollection<T>, IReadOnlyList<T>, IReadOnlyDictionary<K,V> or IReadOnlySet<T> that the field's type implements, matched through the interface map, or Contains on a HashSet<T> or ISet<T>, ContainsKey, ContainsValue, IndexOf, GetEnumerator or TryGetValue declared by a System.Collections type. Every other call on the field is reported, and so is a method group of it passed as a delegate unless it names one of those reads; a call through an interface not named here is never a read. Mutation deeper than one helper is out of scope, and DD0019 does not see it. A [Memoized] field is not reported for being written or called on; MemoizedFieldsAreVerified verifies it instead"
  - key: MemoizedFieldsAreVerified
    statement: "DD0019: [Memoized] on a private instance field of a model class is a claim the rule verifies, not an exemption. It accepts two forms. A value memo: not readonly, typed as a primitive, string, enum, a type DD0004 judges immutable or Nullable<T> of one, written only by 'field ??= expr' or 'if (field == sentinel) field = expr', the guard testing the field or a local copy of it, in one member of the type and no other; expr reads only readonly fields, constants, [Memoized] fields, parameters and its own locals, reads no property of the type that has a setter, and calls only static methods, object's members, members of immutable types, held-collection reads and methods of the type the body check finds change nothing. A per-key memo: a readonly System.Collections.Concurrent.ConcurrentDictionary<K, V> with V immutable, used only through GetOrAdd(key, factory) or GetOrAdd(key, factory, arg) with a static lambda or static method as the factory, in one member, and through its reads; the key and arg are held to the value memo's expression rule. Each departure has its own message: a plain System.Collections collection or array (a race between concurrent readers; use a ConcurrentDictionary), any other mutable type, mutable values, a static, non-private or (for a value memo) readonly field, a dictionary that is not readonly, a second writing member, a factory that is not static, a computation outside the expression rule, the dictionary handed out, and any other write. A [Memoized] field whose shape is refused is reported once, for its shape. Outside a model class the attribute is not checked, because DD0019 does not run there"
  - key: BuildersAreTheEscapeHatch
    statement: "A sealed *Builder in the same namespace is exempt and may not appear on any contract. DD0010 excludes *Builder types from its DomainModel allowance explicitly, because being in a DomainModel namespace would otherwise admit a builder to a contract signature"
